# Adaptive Filter Design for CV-QKD

**Research & Development Internship | QNu Labs Pvt. Ltd.**  
**May–August 2025**

## Overview

This project focused on developing and evaluating digital signal processing (DSP) techniques for continuous-variable quantum key distribution (CV-QKD) receivers, with an emphasis on mitigating practical signal impairments in optical communication systems.

## Key Contributions

- **Chromatic Dispersion Compensation:** Implemented frequency-domain equalization using overlap-save and overlap-add methods for efficient optical-fiber dispersion compensation.
- **I/Q Imbalance Compensation:** Studied a modified Gram–Schmidt orthogonalization procedure (GSOP) to correct quadrature imbalance while avoiding unnecessary signal amplitude normalization.
- **RRC Filtering:** Implemented root-raised-cosine pulse shaping and matched filtering to reduce inter-symbol interference and control signal bandwidth.
- **Performance Evaluation:** Investigated system performance under phase misalignment, gain imbalance, optical signal-to-noise ratio (OSNR) variations, and different fiber lengths.
